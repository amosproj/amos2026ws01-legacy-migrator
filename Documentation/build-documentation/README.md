# Build documentation sources

The Markdown files in this folder are the wiki-ready pages. `Index.md` is the navigation page. `render_pdf.py` formats them into `../../Deliverables/sprint-06/build-documentation.pdf` using ReportLab.

Requirements: Python 3.12 and ReportLab 5.1.0 or a compatible ReportLab release.

From this folder, run:

~~~bash
python3 render_pdf.py
~~~

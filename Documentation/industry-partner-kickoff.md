## 2. Project Background

### 2.1 Project Overview

The project aims to develop a software tool for building and providing a knowledge base to support legacy-to-target software system migrations.

According to the project description, the knowledge base should be represented as a queryable graph.

### 2.2 Capabilities from the Project Description

**Knowledge Base Construction**

The tool should support:

- Code analysis of both legacy and target systems.
- Domain modeling.
- Process and coupling tracking.

**Knowledge Base Usage**

The tool should be able to:

- Answer natural-language questions about migration status.
- Generate standard architecture views directly from the graph.

### 2.3 Initial Technical Context

The project description identifies:

- **Core technologies:** Python and relevant libraries; JavaScript and relevant libraries.
- **Resources:** University HPC resources.
- **Existing tooling:** The project may build upon iteratec's previous internal tooling efforts.
- **Team language:** German or English.

The technical architecture, integration approach, and availability of existing tooling remain to be clarified.
